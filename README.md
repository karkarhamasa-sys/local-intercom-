# Free Intercome (انتركم المصورين)

نظام اتصال داخلي لاسلكي متعدد القنوات (Intercom) أوفلاين مخصص لفرق التصوير، المخرج، وغرفة التحكم، يعمل بالكامل على شبكة Wi-Fi محلية دون الحاجة لاتصال بالإنترنت.

---

## الميزات الرئيسية
- **اتصال محلي آمن (HTTPS/TLS)**: يتم توليد شهادات SSL ديناميكية ذاتياً لتشفير الصوت وحماية البيانات.
- **توجيه ذكي للصوت (Matrix Audio Routing)**: يستطيع المخرج تحديد من يتحدث مع من (توجيه الصوت لمصور معين، فئة معينة، أو الجميع).
- **كود التحقق الديناميكي (PIN)**: رمز أمان عشوائي مكون من 4 أرقام يتغير عند كل جلسة لمنع التداخل أو الدخول غير المصرح به.
- **واجهة مستخدم premium وسلسة**: تصميم مستوحى من واجهات التحكم الاحترافية يدعم الهواتف وأجهزة الكمبيوتر.
- **تطبيق Android مخصص**: تطبيق خفيف ومحسن للتثبيت على هواتف المصورين يمنع انقطاع الصوت ويمنح صلاحيات الميكروفون تلقائياً.

---

## متطلبات التشغيل
- **الخادم (Server)**: جهاز كمبيوتر (Windows/Linux/macOS) مثبت عليه بيئة Go 1.22+ أو تشغيل الملف التنفيذي مباشرة.
- **العملاء (Clients)**: هواتف ذكية (أندرويد أو iOS) متصلة بنفس شبكة الـ Wi-Fi.

---

## طريقة التثبيت والتشغيل

### 1. تشغيل الخادم (Server)
قم بتشغيل الخادم مباشرة من المجلد الرئيسي:
```bash
go run main.go
```
أو تشغيل الملف التنفيذي مباشرة:
```bash
intercom.exe
```

عند بدء التشغيل، سيقوم الخادم بـ:
- توليد رمز جلسة عشوائي (PIN).
- اكتشاف عناوين الـ IP الخاصة بالشبكة المحلية.
- تشغيل خادم HTTPS آمن على المنفذ `8443`.

### 2. تشغيل واجهة المخرج (Director Dashboard)
افتح المتصفح على اللابتوب المستضيف للخادم وتوجه إلى الرابط:
- `https://localhost:8443`
*(ملاحظة: تخطى تحذير الشهادة ذاتية التوقيع في المتصفح بالضغط على Advanced ثم Proceed).*

### 3. تشغيل تطبيق المصورين (Photographers)
- قم بتثبيت ملف الـ APK الموجود تحت المسار:
  [app-debug.apk](file:///E:/free%20intercome/android-client/app/build/outputs/apk/debug/app-debug.apk)
- تأكد من اتصال الهاتف بنفس شبكة الـ Wi-Fi الخاصة باللابتوب.
- افتح التطبيق، وافق على صلاحية الميكروفون، أدخل عنوان الـ IP الموضح في الخادم، المنفذ `8443` ورمز الجلسة (PIN) واسمك، ثم اضغط على **اتصل الآن**.
